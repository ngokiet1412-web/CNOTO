# Integration / acceptance checklist (evidence gated)

- [ ] Owner agrees **as-built** motor, shaft / diff and steer configuration.
- [ ] One authoritative `Assem model.SLDASM` version and dependency-complete Pack and Go selected.
- [ ] Full CAD rebuild completed and missing references enumerated.
- [ ] Exported AP242 STEP can be read and inspected for interferences.
- [ ] Chassis dimensions measured on the actual vehicle (L/W/H, wheelbase, tracks, clearance).
- [ ] Floor mount coordinates and suspect upper/lower part versions reconciled.
- [ ] Final electronics BOM reconciled to installed hardware, power ratings and pinout.
- [ ] Firm-/app source imported without dependencies, secrets or duplicate binary exports.
- [ ] Encoder pulses/revolution, shaft location, ratios and true wheel OD validated.
- [ ] Low-power bench test, failsafe, drive/steer function evidenced.
- [ ] A3 GA drawing with references and revision approved.
- [ ] Parts 2–5 report text/drawings linked to actual evidence.
- [ ] Final field/photo evidence indexed and received review approval.

Checked items require date, person/tool, source and result; these boxes intentionally start unchecked.
