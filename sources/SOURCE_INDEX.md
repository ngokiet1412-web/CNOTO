## Source precedence
1. Physical as-built car with dimensioned inspection record.
2. Latest dependency-complete CAD built and signed off against that car.
3. Versioned individual CAD/drawings/parts with checksum.
4. Group planning sheet and draft report (may disagree; do not assert final from it).
5. Generic catalogue dimensions explicitly labelled preliminary.

For byte-level SHA-256 and repository inclusion status see [UPLOAD_MANIFEST](UPLOAD_MANIFEST.md).
